Support

Updated October 28, 2026

Aviation MCP provides U.S. aviation data and worldwide terrain through aviation-mcp.org. The hosted endpoint is https://aviation-mcp.org/mcp.

Report a problem

Open a GitHub issue with the tool name, approximate request time, relevant public identifiers, and the error or unexpected result. Do not post passwords, API keys, private conversations, or personal flight details.

Data availability

Ask the assistant to call get_data_status for current source cycles and parsing diagnostics. An expired or unavailable dataset is reported explicitly. Partial results can still contain useful records; inspect the accompanying warnings before using them.

Request limits

The hosted service uses on-demand machines, so the first request can take longer. Respect retry information after rate-limit or upstream errors. For large terrain requests, use a shorter corridor or narrower width and preserve any reported coverage gaps.

Documentation

The website setup instructions explain how to connect a client. Implementation and operational documentation are available in the GitHub repository.
