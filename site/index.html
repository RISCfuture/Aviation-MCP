What is
Aviation MCP?

Aviation MCP connects ChatGPT and Claude to U.S. aviation data and worldwide terrain.

MCP — the Model Context Protocol — lets your assistant call tools, retrieve source data, and use the results in its answer. Use it to look up airports and procedures, check weather and NOTAMs, or analyze obstacles and terrain.

17 tools for U.S. aviation data and worldwide terrain.

01 / Airports and runways

Airports

Find airports by identifier, location, runway length, and surface. Retrieve runway details and published airport information.

find_airportsget_airport
Example question
Show Denver’s (KDEN) runways, lengths, and surface types.
02 / Approaches, SIDs & STARs

Procedures

Inspect procedure legs, transitions, altitude constraints, and speed restrictions. Missing legs and unresolved geometry are reported.

find_proceduresget_procedure
Example question
On Boston’s (KBOS) ILS RWY 4R, what altitude is published at GOSHI?
03 / Fixes, navaids and routes

Navigation

Look up fixes, navaids, holds, ILS, FSS, and AWOS. Follow ordered airway segments or find preferred and coded departure routes.

find_navigationget_airwayfind_routes
Example question
What’s on V25 between SNS and PRB?
04 / Boundaries and vertical limits

Airspace

Read controlled and special-use airspace definitions and altitude limits, plus ARTCC, military route, and parachute-area records.

query_airspace
Example question
What are the published vertical limits of Austin’s (KAUS) Class C airspace?
05 / Location and time windows

NOTAMs

Query notices by location, overlapping validity window, and scope. Preserve the original text and schedules, with ingestion freshness and uncertain matches called out.

query_notams
Example question
What NOTAMs affect Chicago O’Hare (KORD) over the next six hours?
06 / METAR, TAF & forecasts

Weather

AWC aviation reports, with Open-Meteo forecasts filling gaps. Choose providers and parse supplied METAR, TAF, or winds-aloft reports. Modeled values and their sources stay labeled.

get_weather · parse_weather
Example question
Compare the latest METARs along KATL–KCLT–KRDU. Where are the lowest ceilings, poorest visibility, and strongest winds?
07 / Aircraft characteristics

Aircraft

Look up published aircraft characteristics from the FAA Aircraft Characteristics Database. This is type-level data, not an aircraft registration search or an AFM performance calculator.

get_aircraft
Example question
What are the published dimensions of the Cirrus SF50?
08 / Nearby and along a route

Obstacles

Search FAA obstacle records around coordinates or along coordinate routes. Keep elevation above mean sea level separate from height above ground.

query_obstacles
Example question
Find the ten highest obstacles within 1 NM of the WOHLI–MAVKC–RW30 final-approach path on Half Moon Bay’s (KHAF) RNAV (GPS) RWY 30. Show MSL elevations and AGL heights.
09 / Native elevation cells

Terrain

Find the highest Copernicus terrain along a coordinate corridor. Compare a supplied climb gradient using an explicit EGM2008 starting altitude. Unknown coverage stays unknown.

query_terrain
Example question
What’s the highest terrain within 1 NM on either side of a direct route from Truckee (KTRK) to Mammoth Yosemite (KMMH)?
10 / Coordinates & geometry

Geography

Convert coordinate formats and compute distances, bearings, and route geometry. Ask for the units and reference conventions alongside the result.

convert_coordinates · compute_geometry
Example question
What are the direct distance in nautical miles and initial true bearing from New York (KJFK) to Los Angeles (KLAX)?
11 / Availability and provenance

Source status

Check which datasets are available, their effective cycles, and source versions before relying on an answer. Expired periodic data is unavailable.

get_data_status
Example question
Which datasets are currently available, and what source versions are in use?

Data availability and parsing gaps are reported at query time. Aviation coverage is U.S. only; terrain coverage is worldwide.

A research and planning tool. Verify operational decisions with official aviation sources. Terrain comparisons do not establish certified obstacle clearance or aircraft performance.

Connect the server

Use the same endpoint in ChatGPT or Claude.

Remote MCP endpointhttps://aviation-mcp.org/mcp

Hosted and read-only. No Aviation MCP account, API key, or local install required. Your AI provider’s plan and workspace permissions still apply.

ChatGPT

  1. Add a custom MCP server

    On ChatGPT web, open Plugins, select +, then Add custom MCP server.

  2. Add Aviation MCP

    Name it Aviation MCP, paste the endpoint above, and choose no authentication. Review the warning and discovered tools, then create the plugin.

  3. Bring it into your conversation

    Select the plugin in your chat and ask one of the example questions below. Approve tool calls when prompted.

Workspace permission is required. If you have the legacy interface, use Settings → Apps → Create. The current Plugins flow does not require Developer Mode.

OpenAI setup guide

Claude

  1. Open your connectors

    Go to Customize → Connectors. Choose + Add → Add custom connector.

  2. Add Aviation MCP

    Enter Aviation MCP and paste the endpoint above. Continue, choose No sign in, and finish adding the connector.

  3. Enable it in your chat

    In a conversation, open + → Connectors and enable Aviation MCP. Ask a question and review any tool approval prompts.

For Team or Enterprise, an authorized owner first adds the connector in organization settings. Availability and controls depend on your account.
